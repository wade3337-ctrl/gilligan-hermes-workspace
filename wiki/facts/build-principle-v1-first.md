# Build principle — prototype in TRIM IT V1 first

**🧱 BUILD PRINCIPLE (Skipper, 2026-06-23):** prototype each new tool in **TRIM IT V1 first** — build, test, refine on real V1 data — **then that proven model becomes the FRAMEWORK arbor-core inherits.**

- **V1 = proving ground; arbor-core gets the cleaned-up version.**
- Example: Scott's Manager Dashboard de-dupe / account logic → arbor-core's clean account model.
- Project: `arbor-stack/pipeline-tool/PROJECT-scott-manager-dashboard.md`.
