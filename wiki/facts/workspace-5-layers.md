# 🗂️ Workspace = 5 layers → READ `ROUTING.md` FIRST

The workspace is organized in **5 layers**. Before doing anything, read `ROUTING.md` — it's the map.

## The 5 layers
1. **Identity** — root `.md` files (the "who I am" layer).
2. **Routing** — `ROUTING.md`, the navigation map.
3. **`contracts/`** — how we do each kind of work → [[contracts-map]].
4. **`reference/`** — look-it-up standards & facts.
5. **Artifacts** — `~/arbor-stack/` (the actual project material).

## Rule
When adding a **contract, reference, or major artifact**, update `ROUTING.md` **and** the relevant INDEX so the map stays current.
