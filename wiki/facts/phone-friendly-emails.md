# 📱 Emails must be phone-friendly

Reps read on phones, so every email:
- **Short lines.**
- **No aligned columns / deep indents.**
- **Key number first.**

## UI page standards (related)
For on-page UI rules — welcome modal w/ colored-emoji front page (§2A); **NO permanent technical text** (put "how it's calculated" in the "?" pro-tip popup, `assets/protips/`); **.cfm with emoji/non-ASCII needs a UTF-8 BOM** or ColdFusion serves mojibake (`ssh type` strips it → re-add before deploy) — see **[[gsts-ui-style-guide]]** (`reference/GSTS-UI-STYLE-GUIDE.md`) + [[gsts-ui-spec]] (`arbor-stack/gsts-ui-spec-v1.0.md`).
