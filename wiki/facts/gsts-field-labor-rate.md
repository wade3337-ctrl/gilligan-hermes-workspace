# GSTS field-labor cost ≈ $36/hour (fully loaded)

**The reusable number:** GSTS **direct-labor cost per field hour** (groundsmen / trimmers / drivers), fully loaded (wage + payroll burden + health), is **~$36/hour**. Two independent sources agree:
- **Dec-2025 financials** "DL Cost per Hour" = **$35.61** (trend: 2023 $39.66 → 2024 $36.45 → 2025 $35.61).
- **2026 payroll budget** fully-loaded = **$36.57/hour**.

An **overtime** hour ≈ 1.5× base + burden ≈ **~$46–50/hour**.

**Where it lives:** Skipper-provided files in `~/.openclaw/media/inbound/` — *December_2025_Financials* (income-statement "DL Cost per Hour" row, ~15-mo rolling tab) and *2026_Budget_-_Fixed_Payroll_Forecast* (per-person Base Rate + V&H + tax + health → Total Cost / 2,080 hrs).

**Key budget basis:** the **2026 budget assumes 40-hour weeks** — 2,080 regular hrs/person, only ~$219K OT budgeted all year (~3.5% of $6.3M DL). So crews working 45+ are on **unbudgeted OT**; cutting to 40 = back to budget. Field DL headcount = **83** (29 Sr Trimmer, 26 Trimmer, 25 Groundsman, 3 Groundsman/Driver; base $22–$36.55, avg $27.45).

Used in → [[analysis-north-yard-hours]]. TPH (revenue-per-hour, target $130) is the *revenue* side; this is the *cost* side.
