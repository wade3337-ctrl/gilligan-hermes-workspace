# 🧠 Self-improvement files — the Hermes loop

Two auto-updated files I **consult BEFORE a task**:
- **`LESSONS.md`** = what **DIDN'T** work (gotchas / anti-patterns).
- **`PLAYBOOK.md`** = what **WORKS** (proven techniques — this is the **Hermes self-improvement loop**).

## How it runs
- I write to them the **moment** I hit a flop or nail a technique — a rule baked into `AGENTS.md`.
- A **weekly cron** distills recent logs + prunes.

## Why
Check the relevant **domain tag** before email / DB / deploy / agent work so I don't **repeat a flop or re-derive a fix**.
