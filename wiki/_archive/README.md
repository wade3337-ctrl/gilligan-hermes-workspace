# _archive — verbatim source artifacts, not atomic notes

Files here are **copies of external source documents** (handbooks, statements, packets) kept
verbatim for reference. They are deliberately exempt from the atomic-note rules:

- Not required to be atomic, short, or MOC-listed — splitting them would make them *wrong*.
- Still **valid `[[wikilink]]` targets** (Obsidian resolves by filename, not folder), so nothing breaks.
- `wiki-lint` indexes them as link targets but does not quality-check them.

Rule of thumb: **our knowledge → an atomic note. Someone else's document → here.**
