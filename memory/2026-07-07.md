## Part (b) STEP 1 — multi-color zone extractor WORKS (commit 928ba08)
- New MULTIZONE_HTML + extract_multizone() + `run(mode='zones')` in georef_map.py. Pipeline: HSV hue-histogram → dominant fill colors → **4× downsample** each color mask (morphological close, bridges CAD linework that fragments hand-colored fills) → connected components → **Moore boundary trace** (concave) → **closed-curve Douglas-Peucker** (plain DP collapses a closed loop → split at farthest point) → project each polygon to GPS via the georef affine.
- **Two bugs found+fixed via debug:** (a) components fragmented by linework (fixed w/ downsample); (b) closed-loop DP degenerate a===b → collapsed to 2 pts (fixed w/ simplifyClosed).
- **Verified on La Paz Colored Map:** 16 zones extracted + placed on satellite (RMS 2.8m), tracing the real property perimeter. Screenshot: `memory/multizone-step1-lapaz.png`.
- **Known rough edges (next iteration):** same-color fragments should merge into one zone; drop noise picked up inside excluded features (reservoir hatching); cleaner boundaries; legend-label each zone; then wire mode='zones' into maps_api + a review/commit UI.
