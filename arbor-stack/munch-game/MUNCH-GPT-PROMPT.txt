=== THE GAME (fixed spec — do not redesign) ===
Title: MUNCH!
Genre: Pac-Man-style top-down MAZE muncher, tree-care themed.
Concept: You are a LADYBUG clearing a giant tree of pests. Ladybugs are real biocontrol — they
  eat aphids — so the premise is on-theme: munch every dew drop in the branch-maze, dodge the
  pests, and clear the tree.
Core loop:
  - The maze IS the tree's branch/root network (a grid of corridors), with tunnel wraparound edges.
  - Munch all the DEW DROPS (the "dots") to clear a level.
  - GOLDEN SAP DROPS are the power pellets: for a few seconds the pests turn blue and flee, and you
    can munch them for escalating points (200/400/800/1600); munched pests respawn from the "hive".
  - Bonus item: a GOLDEN ACORN appears mid-level for bonus points, then disappears.
Enemies (exactly 4 pests, each with a distinct Pac-Man-style personality):
  - APHID  = the direct chaser (targets your tile).
  - BEETLE = the ambusher (targets a few tiles ahead of you).
  - BORER  = the wanderer (semi-random / flanks).
  - WASP   = the guard (patrols, only chases when you're close).
  They alternate SCATTER (retreat to corners) and CHASE phases on a timer. In power mode they are
  FRIGHTENED (blue, slow, flee) until it wears off (with a blink warning near the end).
Player/rules: 3 lives; touching a non-frightened pest = lose a life and reset positions; clearing
  all dew drops = next level. AT LEAST 6 LEVELS, each with a different maze layout and faster/
  smarter pests as you climb. Persist high score in localStorage.
INTERMISSIONS (Ms. Pac-Man style — REQUIRED): between levels, play a short (~5-8s) animated
  cutscene vignette that advances a little wordless story. Six bespoke story beats, in order:
    After L1  "They Meet"     — our ladybug spots a SECOND ladybug across a branch; a shy hello.
    After L2  "The Chase"     — a big beetle comedically chases both ladybugs across the screen.
    After L3  "Teamwork"      — the two ladybugs turn and munch the beetle together; it flees.
    After L4  "New Growth"    — the tree greens up, a leaf unfurls / a bud pops.
    After L5  "A Little One"  — a tiny baby ladybug appears and toddles after them.
    After L6+ "The Tree Thrives" — full-bloom celebration; beyond L6 the vignettes recur/escalate
                                   so EVERY level gap always shows something.
  Each vignette has a title card (e.g. "Act 1 — They Meet"), is skippable with any key/tap, and is
  drawn in code like the rest of the game (no external assets).
Screens: Title, in-game HUD (score, high score, lives, level), Ready!/Get-set intro, Pause,
  Game Over, the between-level INTERMISSION vignettes, and a short "Tree Cleared!" flourish.
Art direction: cute cartoon / storybook (friendly ladybug, expressive pests, leafy maze walls).
  FALLBACK: if a consistent cartoon look cannot be achieved, switch to a clean 16-bit pixel-art
  style. Either way, ALL art is drawn IN CODE (canvas primitives and/or inline SVG data-URIs) —
  NO external image files.
Brand wink (light, tasteful): use a Great-Scott-green accent in the palette and hide ONE small
  Easter egg in a corner of the maze/background — a tiny hard-hat or a small "GSTS" truck. Do not overbrand.
Controls: FULL RESPONSIVE. Desktop = Arrow keys/WASD to steer (4-direction grid movement with
  input buffering so turns feel snappy) + P (pause). Mobile = swipe to steer OR an on-screen d-pad
  that appears on touch devices. Canvas scales to any window size and keeps its aspect ratio.

=== HARD CONSTRAINTS (non-negotiable) ===
- Output = ONE .html file. Everything inline: HTML, CSS, JS, all art, all audio.
- ZERO network requests. No CDNs, no external images, no external fonts, no audio files.
- Audio = synthesized at runtime via the WebAudio API (chomp/waka loop, power mode, eat-pest,
  death, level-clear, bonus) + a mute toggle. No files.
- Must run by simply opening the file (file://) in a modern browser with NO console errors.
- Target ~60fps using requestAnimationFrame and a fixed-timestep update loop.
- Grid-based movement: entities move on a tile grid; movement is smooth but logically tile-locked.
- Vanilla JS + Canvas. No frameworks, no build step. Self-contained; embeddable via <iframe>.
- SINGLE-INTEGRATOR RULE: exactly one integrator owns MUNCH.html; conceptually no other role writes
  to it directly — each role's work is merged in by the integrator so the file stays coherent.
